Kit and sounds: five settings per drum

LEVEL is the volume of the drum, TUNE 64 = nominal pitch, DECAY and TONE depend on the drum (see the README, drum machine chapter), PAN 64 = centre. Change a slider and the drum plays.

The machine (USB)

Connect the Pico's own USB port (the drum firmware must be running; close any serial monitor first). Sending stops the machine first, because the firmware refuses a new state while playing. Sending replaces the machine's kit, 16 patterns, song and settings in RAM; "save to flash" keeps it over a power cycle. pyserial is not installed: python3 -m pip install pyserial
(uses the instrument row last clicked)

Machine settings stored in the image

Files

The image (.bin, 4247 bytes) is exactly what the machine keeps in flash, so it can also be copied to the LittleFS partition as /drums.bin. Pattern and kit names exist only in the .json project: the machine has no names.
